# Documentation index

| Folder | Contents |
| :--- | :--- |
| `competition/` | The official problem description and rules (PDF and Markdown conversion) and a short summary of the case. Source of truth for what must be submitted. |
| `design/` | Working design notes. `architecture-draft.vi.md` is the original brainstorm (Vietnamese); the submitted architecture document will be `architecture/overview.md` (English). |
| `architecture/` | One note per feature: a Mermaid diagram, the owning module, an ERD where data flows. Added by the PR that builds the feature. |
| `previews/` | Screenshots of UI changes, committed by the PR that changes the UI. |
| `evidence/` | Execution evidence for submission: transaction hashes with explorer links. |

Naming: lowercase, hyphens, no spaces. Everything new is written in English.
